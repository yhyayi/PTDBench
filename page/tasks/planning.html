Case #1 — Logistics Planning

Difficulty: Medium
Problem
You have 3 trucks (capacity 10 each) at depot D. Deliver packages to cities A(5 units), B(8 units), C(7 units). Roads: D→A(2h), D→B(3h), D→C(4h), A→B(1h), B→C(2h). Minimize total delivery time. Trucks can make multiple trips.
Solution
Truck 1: D→A(5 units, 2h) → done.
Truck 2: D→B(8 units, 3h) → done.
Truck 3: D→C(7 units, 4h) → done.

All deliveries complete in parallel. Total time = max(2, 3, 4) = 4 hours.
Reward Function
goal_check(all_delivered=True) * efficiency_bonus(time <= optimal_time * 1.2) → reward = completion + 0.3 * efficiency

Case #2 — Task Scheduling with Dependencies

Difficulty: Hard
Problem
Schedule 6 tasks on 2 workers. Dependencies: T1→T3, T2→T3, T3→T5, T4→T6, T5→T6. Durations: T1(3), T2(2), T3(4), T4(3), T5(2), T6(1). Find the minimum makespan schedule.
Solution
Critical path: T1→T3→T5→T6 = 3+4+2+1 = 10
Optimal schedule:
Worker A: T1[0-3] → T3[3-7] → T5[7-9] → T6[9-10]
Worker B: T2[0-2] → T4[2-5]

Minimum makespan = 10
Reward Function
valid_schedule(respects_deps=True, workers<=2) AND makespan_score(plan_time, optimal_time) → reward
