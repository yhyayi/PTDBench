Case #1 — Quantum Mechanics

Difficulty: Hard
Problem
A particle is in the ground state of an infinite square well of width L. The well is suddenly expanded to width 2L (keeping the left wall fixed). What is the probability of finding the particle in the ground state of the new well?
Solution
The initial state is ψ₁(x) = √(2/L) sin(πx/L) for 0 < x < L.
The new ground state is φ₁(x) = √(1/L) sin(πx/2L) for 0 < x < 2L.

P = |⟨φ₁|ψ₁⟩|² = |∫₀ᴸ √(1/L) sin(πx/2L) · √(2/L) sin(πx/L) dx|²

Evaluating the integral: P = 32/(9π²) ≈ 0.36
Reward Function
numerical_match(answer, 32/(9*pi^2), rtol=0.01) AND has_integral_setup(steps) → reward = 0.7*correct + 0.3*derivation

Case #2 — Organic Chemistry

Difficulty: Medium
Problem
Predict the major product when 2-methylbut-2-ene reacts with HBr in the presence of peroxides. Explain the mechanism and regiochemistry.
Solution
With peroxides, HBr addition proceeds via anti-Markovnikov radical mechanism:
1. Initiation: peroxide → radicals → Br·
2. Propagation: Br· adds to less substituted carbon (anti-Markovnikov) forming more stable tertiary radical
3. H-abstraction completes addition

Major product: 1-bromo-2-methylbutane
Reward Function
product_match(answer, "1-bromo-2-methylbutane") AND mentions(["radical", "anti-Markovnikov"]) → reward
