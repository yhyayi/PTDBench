Sample Cases

Representative examples from this task.

Case #1 — Propositional Logic

Difficulty: Easy
Problem
Given premises: (1) If it rains, the ground is wet. (2) If the ground is wet, the game is cancelled. (3) It is raining. Prove: The game is cancelled.
Solution
1. It rains (premise 3)
2. The ground is wet (modus ponens: premise 1 + step 1)
3. The game is cancelled (modus ponens: premise 2 + step 2) ∎
Reward Function
proof_verifier(steps) → reward = valid_steps / total_steps (each step must cite a valid rule + antecedents)

Case #2 — Constraint Satisfaction

Difficulty: Hard
Problem
Five people (A, B, C, D, E) sit in a row. Constraints: (1) A is not adjacent to B. (2) C sits to the left of D. (3) E sits at one of the two ends. (4) B is adjacent to C. How many valid arrangements exist?
Solution
Enumerate by E's position (seat 1 or seat 5), then place B-C pair respecting constraint 2 and 4, finally place A and D.

After exhaustive enumeration: 8 valid arrangements.
Reward Function
exact_match(answer, "8") AND valid_reasoning_chain(steps) → reward = 0.5 * correct + 0.5 * reasoning_score
