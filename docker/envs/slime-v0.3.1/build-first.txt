# Packages that must be installed before the rest, by name.
#
# Same shape as docker/envs/slime-rc0/build-first.txt; see there for the full
# rationale. Names only, no versions -- the pin is read out of requirements.txt,
# which stays the single source of truth. docker/collect_envs.py fails if a
# name here is missing from requirements.txt.
#
# flash_attn is a prebuilt wheel when docker/wheels has a match (see
# fetch-cuda-wheels.sh); otherwise it compiles here against this torch, which
# is why torch and the build backend must already be present.
# transformer_engine is the PyPI 2.16.1 split (cu13 wheel + torch sdist).
# transformer_engine_cu13 belongs here so the core library is on disk before
# transformer_engine_torch compiles against it. 2.16.1 is published against
# both CUDA majors, so the 13.0 move is a rename here, not a version bump.
#
# Torch's own runtime deps come after the backend block. CUDA wheels are
# installed --no-deps (so pip does not follow the PyTorch index onto
# pythonhosted.org), and the bulk pass is --no-build-isolation, so
# transformer_engine's setup imports torch before those deps would otherwise
# land. Missing nvidia-cudnn-cu13 here fails metadata generation with
# ImportError: libcudnn.so.9.
