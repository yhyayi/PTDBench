# Packages whose build needs more than `pip install <pin>`. See
# docker/envs/slime-rc0/build-flags.txt for the format and for why apex is
# mandatory rather than optional on a slime environment.
#
# Short version: megatron.core's ColumnParallelLinear defaults to
# gradient_accumulation_fusion=True and raises a RuntimeError at construction
# time if fused_weight_gradient_mlp_cuda cannot be imported. Without
# --cpp_ext --cuda_ext, apex installs as pure Python and that module is absent.
#
# DeepEP is deliberately absent: it is for MoE all-to-all and every task on
# this environment is dense (Qwen3-4B, Qwen2.5-3B).
#
# torch_memory_saver is built from source (zhuzilin pin, not PyPI). setup.py
# refuses to configure without TMS_CUDA_MAJOR so the hook .so is suffixed
# _cu13 and matches torch 2.11.0+cu130. A bare pip install dies at metadata.
apex -- --config-settings "--build-option=--cpp_ext" --config-settings "--build-option=--cuda_ext"
torch_memory_saver TMS_CUDA_MAJOR=13 --
