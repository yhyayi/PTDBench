# 隐藏标准诊断

## 核心结论和归因边界

这是发生生成分布退化的、不健康的全参数 on-policy 排序蒸馏训练。被考查的具体问题是
目标函数对候选集相对于词表外部的概率质量缺乏约束：内部排序改善或排序 loss 下降，
不足以保证生成分布保留在教师认为合理的候选上。

这个目标函数缺口可以严格证明，并且记录中的概率质量、熵、验证结果及固定前缀观测
与之相符。不能把证据夸大为“已证明唯一导致这次训练失败的因素”，也不能断言所有
排序蒸馏都必然崩塌。全参数更新、长推理、截断和缺少分布锚定是本次环境/候选放大因素，
未完成单因素重训消融。是否需要某个特定超参数才会触发，不能由现有证据唯一确定。

## 数学机制（必须覆盖）

冻结教师在学生前缀上给出有序集合 $C=(v_1,\dots,v_K)$，$K=8<|V|$。
每个位置的目标是

$$\ell(z)=\frac{1}{K-1}\sum_i\operatorname{softplus}(z_{v_{i+1}}-z_{v_i}).$$

它只依赖集合内部差值。对所有 $v\in C$ 同时加偏移 $\delta$，保持 $v\notin C$
不变，则 $\ell(z')=\ell(z)$。这是**仅平移候选集合**，不是平移整个词表；后者连概率
都不改变，不能说明这里的缺口。也不是对学生 logits 任意缩放不变。

令 $A=\sum_{v\in C}e^{z_v}$、$B=\sum_{v\notin C}e^{z_v}>0$，则

$$m_C(\delta)=\sum_{v\in C}\pi_\theta(v)
=\frac{e^{\delta}A}{e^{\delta}A+B}\longrightarrow0\quad(\delta\to-\infty).$$

因此 loss 完全相同可以对应从高到极低的候选总概率。log-prob 中的完整词表 softmax
归一化项在相邻差值中抵消；调用 full-vocabulary log-softmax 不能自动补上这个约束。
独立 logit 坐标下，候选集外的直接梯度为零，但神经网络共享参数，集外 logits
仍能随参数更新改变；不能据此声称它们在训练时固定不动。

`verl/verl/trainer/opd/order_only.py::direct_topk_loss` 实现相邻 softplus，
`verl/verl/trainer/opd/losses.py::opd_direct_topk_loss` 聚合回复与 batch。
direct objective 路径没有加入候选质量、完整分布匹配、reference KL 或监督标签锚定项。
历史配置的 `opd.is_norm` / `opd.outside_bucket` 是其他路径选项，不能仅凭名字认为
当前 direct loss 已包含这种约束。

## 证据

- 两组均运行到 200 步，AIME25 在 step 100 为 0%，三个评测集在 step 140 全为 0%。
- A：`actor/opd_student_mass` 从 step 1 的 0.9319356 降到 step 200 的 0.000666883；
  `actor/entropy` 从 1.021756 升到 11.752307。
- B：上述质量从 0.9326616 降到 0.000378210；熵从 0.994823 升到 11.800219。
  全词表最大熵约为 $\log(151936)\approx11.93$。这是熵增长、分布趋平型退化，
  不应误说成低熵、单 token 集中型坍塌。
- 后期真实生成片段含随机、多语言混杂内容，支持生成能力退化，不能只归因于答案提取器。
- 固定前缀（A、3 条初始正常轨迹、48 个采样位置、CPU FP32）：step 0→200 排序 loss
  0.905397→0.657450，候选质量 0.991229→0.774664，熵 0.248962→2.780445，
  top-8 overlap 0.703125→0.622396。该小样本控制了前缀内容，说明目标改善与分布退化
  可以共存；不是全面性能测评，不能与 on-policy batch 均值混为一谈。
- B 使用 FP32 teacher head 和 tie masking，teacher tie rate 从 A 初期约 10% 降到
  百万分之一级，仍出现非常接近的崩塌。teacher ties 因而不足以解释主要现象。
- 所有解析的数值指标有限，actor/rollout 概率相关性超过 0.9995。没有观察到 NaN、
  持续梯度爆炸或明显权重同步失效的证据；这些并不是对所有实现路径的绝对排除。
- 历史 `opd/topk_overlap` / `opd/top1_agreement` 恒为 1 是已说明的独立仪表问题。
  不能拿它们证明排序学得完美，也不能把这一监控问题替代目标函数缺口作为主诊断。

## 评分约束（由共享 judge 使用）

按共享维度 verdict/root_cause/evidence 评分，权重 0.2/0.6/0.2，总分至少 0.8 通过。

- 完整答案应指出内部排序与候选总概率的区别，解释候选共同偏移不受罚（或等价的
  归一化抵消机制），并结合概率质量/熵与验证或固定前缀证据。数学公式不是硬性格式要求。
- 只说“KL 太小”“没有正则”“学习率太大”“全参过拟合”，但不解释上述机制：
  root_cause_score **最高 0.5**，即使其他维度满分也不能通过。
- 把 teacher BF16 ties、NaN、损失符号反了、历史监控错误作为唯一根因：
  root_cause_score **最高 0.25**。
- 将候选共同偏移混同于全词表共同偏移，或把学生缩放称为严格不变：
  若没有另一个正确机制解释，root_cause_score **最高 0.5**。
- 数学缺口正确但声称其必然主动把质量推向外部、已证明唯一触发原因：
  root_cause_score **最高 0.5**。不受惩罚不等于必然被优化器选择。
- 具体数字可有合理舍入，无需逐一列出。使用全部 on-policy 证据而未提固定前缀也可以
  获得通过；不能要求必须引用隐藏数值探针。
- 不评分修复方案，不要求 LoRA、KL 或某个唯一补丁；可行改进建议不替代诊断。
