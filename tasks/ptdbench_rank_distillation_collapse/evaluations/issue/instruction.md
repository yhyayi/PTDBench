# 诊断任务

你得到一个 on-policy 蒸馏工作区，包含训练框架、入口脚本、方法说明和两次实际运行的日志。
训练完成且主要数值保持有限，但验证成绩和生成质量明显退化。

请阅读 `workspace/README.md` 中的方法定义，检查代码、配置与实验记录，提出能够解释
这一现象的具体诊断。说明证据支持什么、还不能确定什么。不要把正常结束或某个 loss
下降直接当作训练成功。

允许读取工作区和已准备的 Python 环境，运行 CPU 测试或小型数值实验。可以创建临时探针，
但本级别不要求修改训练实现、不要求修复或重跑 GPU 训练。禁止访问网络、安装依赖，
禁止读取工作区及正常运行环境之外的任务元信息、隐藏答案或评测器。

将最终报告写入 `$PTDBENCH_RESULTS/agent_answer.md`。只在聊天中回复不算提交。
报告应包含：

1. 训练是否健康及关键表现；
2. 具体机制，以及关联的代码或公式；
3. 至少两类可核验的证据；
4. 与其他合理解释的区分，以及结论的适用范围。

不要求提供补丁。评分不依赖特定措辞或英文术语，中文报告可以。
